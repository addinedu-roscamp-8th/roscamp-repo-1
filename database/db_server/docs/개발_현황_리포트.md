## 3. 구현 완료 항목

### 3.1 모델·라우트

- **모델**: `app/models_kitchmatic.py` — Menu, Ingredient, Recipe, RecipeStep, Inventory, InventoryTransaction, Robot, Order, QualityCheckResult (schema.sql 매핑)
- **라우트**: `app/routes/kitchmatic/`  
  - menus, ingredients, recipes(단계 포함), inventory(재고·재고거래), robots, orders, quality_checks  
  - 공통: 목록 `{"items", "count"}`, UUID는 `_parse_uuid()`, Flasgger YAML docstring

### 3.2 앱·문서

- **앱**: `app/__init__.py` — Kitchmatic Blueprint 8개 등록, Swagger 태그 추가, `app.models_kitchmatic` import
- **api-docs**: 모든 Kitchmatic 태그에서 GET/POST/PUT/DELETE 명세·테스트 UI 노출 (Flasgger YAML docstring 통일)

### 3.3 테스트

- **파일**: `tests/test_kitchmatic_api.py` — 39개 테스트 (Menus, Ingredients, Recipes, Recipe steps, Robots, Inventory, Orders, Inventory transactions, Quality checks)
- **실행**: `PYTHONPATH=. python3 -m pytest tests/test_kitchmatic_api.py -v` → **39 passed**
- **conftest**: TestConfig에서 동일 DB 사용, `TestConfig` 자기참조 NameError 수정
