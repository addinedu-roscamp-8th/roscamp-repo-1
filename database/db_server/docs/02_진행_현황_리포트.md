## 2. 02 완료 항목

### 2.1 SQLAlchemy 모델 (schema.sql)

- **파일**: `app/models_kitchmatic.py`
- **내용**: `app.models.Base` 공유, schema.sql 테이블 전부 매핑
  - `Menu`, `Ingredient`, `Recipe`, `RecipeStep`, `Inventory`, `InventoryTransaction`, `Robot`, `Order`, `QualityCheckResult`
  - PK/FK, CHECK 제약, UniqueConstraint 반영
- **앱 연동**: `app/__init__.py`에서 `import app.models_kitchmatic` 로 메타데이터 등록

### 2.2 CRUD 라우트 (prefix `/kitchmatic`)

모든 라우트는 `app/routes/kitchmatic/` 아래에 구현되어 있으며, Flasgger docstring 포함.

| 리소스 | Blueprint 파일 | URL prefix | 제공 메서드 |
|--------|----------------|------------|-------------|
| 메뉴 | `menus.py` | `/kitchmatic/menus` | GET(목록/단건), POST, PUT, DELETE |
| 식재료 | `ingredients.py` | `/kitchmatic/ingredients` | GET(목록/단건), POST, PUT, DELETE |
| 레시피 | `recipes.py` | `/kitchmatic/recipes` | GET(목록/단건), POST, PUT, DELETE |
| 레시피 단계 | `recipes.py` | `/kitchmatic/recipes/<id>/steps` | GET(목록), POST / GET/PUT/DELETE `<rid>/steps/<sid>` |
| 재고 | `inventory.py` | `/kitchmatic/inventory` | GET(목록/단건), POST, PUT, DELETE |
| 재고 거래 | `inventory.py` | `/kitchmatic/inventory-transactions` | GET(목록/단건), POST |
| 로봇 | `robots.py` | `/kitchmatic/robots` | GET(목록/단건), POST, PUT, DELETE |
| 주문 | `orders.py` | `/kitchmatic/orders` | GET(목록/단건), POST, PUT, DELETE |
| 품질검사 | `quality_checks.py` | `/kitchmatic/quality-check-results` | GET(목록/단건), POST, PUT, DELETE |

- **공통**: `_helpers.row_to_dict()`, UUID 경로는 `<id>`(문자열) + `_parse_uuid()` 처리, 목록 응답은 `{"items": [...], "count": len(rows)}` 형태
- **재고 거래**: `inventory_id`, `order_id` 쿼리 파라미터 필터 지원 (UUID 파싱 실패 시 필터 생략)

### 2.3 앱 등록 및 Swagger

- **`app/__init__.py`**
  - Kitchmatic Blueprint 8개 등록: menus, ingredients, recipes, robots, inventory, inventory-transactions, orders, quality_checks
  - Swagger template에 Kitchmatic 태그 7개 추가 (Menus, Ingredients, Recipes, Robots, Inventory, Orders, Quality)
- **API 문서**: `/api-docs` 에서 Flasgger로 모든 Kitchmatic 엔드포인트 명세 확인 가능 (각 라우트 docstring 기반)

### 2.4 기존 API 유지

- `health`, `orders`, `inventory`, `analytics`, `dashboard`, `orders_ui`, `ingredients`, `menu_recipe` Blueprint는 변경 없이 유지됨.
