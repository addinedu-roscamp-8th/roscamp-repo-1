ROS 2 TOPICS (Current - Namespace Based)
================================================================================

Global Topics:
  /fms/order_request          - OrderRequest message
  /fms/fleet_status           - FleetStatus message
  /fms/delivery_complete      - DeliveryComplete message
  /fms/goal_arrived           - goal_arrived notification (String JSON)
  /fms/precision_parked       - precision_parked notification (String JSON)
  /fms/food_loaded            - food_loaded notification (String JSON)
  /fms/food_load_request      - food load request (String JSON)

Per-Robot Namespaces:
  /pinky1/pose                - Robot 1 position
  /pinky1/battery/voltage     - Robot 1 battery voltage
  /pinky1/battery/present     - Robot 1 battery status
  /pinky1/navigate_to_pose    - Robot 1 navigation action

  Same structure for /pinky2 and /pinky3

================================================================================
MESSAGE TYPES
================================================================================

OrderRequest:
  - order_id (string)
  - menu_id (string)
  - table_number (string)
  - quantity (int32)
  - sauce_type (string)
  - voice_order (bool)
  - created_at (Time)

RobotStatus:
  - robot_id (string)
  - status (string)
  - current_pose (Pose)
  - battery_voltage (float32)
  - battery_present (bool)
  - timestamp (Time)

FleetStatus:
  - robots (RobotStatus[])
  - pending_orders (int32)
  - active_orders (int32)
  - timestamp (Time)

goal_arrived (JSON String):
  {"robot_id": "pinky1", "location": "point13", "timestamp": 1708900800.123}

precision_parked (JSON String):
  {"robot_id": "pinky1", "location": "pickup_spot", "timestamp": 1708900802.456}

food_loaded (JSON String):
  {"robot_id": "pinky1", "order_id": "ORD-...", "menu_id": "M001", "quantity": 1, "timestamp": ...}

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "No module named fleet_interfaces"
  Solution: Ensure fleet_interfaces is built
    colcon build --packages-select fleet_interfaces

Issue: Port test shows all closed
  Solution: 
    - Verify robots are powered on
    - Check WiFi connection to "kitchmatics"
    - Verify network configuration in fms/config/network_config.yaml
    - Test with: ping 192.168.1.7

Issue: "Failed to parse goal_arrived message"
  Solution:
    - Check JSON format in message data
    - Verify all required fields are present
    - Inspect message with: ros2 topic echo /fms/goal_arrived

Issue: Mock not receiving messages
  Solution:
    - Verify FMS is publishing to correct topic
    - Check ROS_DOMAIN_ID (currently using namespaces)
    - Verify message format matches expected structure
    - Check mock logs for subscription confirmation
