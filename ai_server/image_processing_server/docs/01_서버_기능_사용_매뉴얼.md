## 1. 서버 개요

| 항목 | 설명 |
|------|------|
| **역할** | JetBot(라즈베리파이) 카메라 영상/이미지를 YOLO로 분석하고, 결과를 JSON으로 반환 |
| **기본 주소** | `http://<서버IP>:5001` |
| **기본 포트** | 5001 (JetBot 웹캠 서버 5000과 구분) |

- **이미지/영상 소스**: 서버가 JetBot([http://192.168.1.6:5000](http://192.168.1.6:5000))의 `/snapshot`, `/video_feed`를 내부적으로 호출합니다.  
- **호출 측(ROS2 등)**: 이미지를 보낼 필요 없이 **GET 요청만** 하면 됩니다. AI 분석 서버 샘플: [http://192.168.0.27:5001](http://192.168.0.27:5001).

## 2. 실행 방법

### 2.1 사전 요구사항

- Python 3.10 이상
- 의존성 설치: `pip install -r requirements.txt`  
  (flask, requests, opencv-python-headless, ultralytics, PyYAML)

### 2.2 서버 실행

```bash
# 1) 프로젝트 폴더로 이동
cd /home/addinedu/Documents/ai_server

# 2) 가상환경 사용 시
./venv/bin/python app.py

# 또는 가상환경 없이
python app.py
```

- 기본: `0.0.0.0:5001` 에서 수신 (같은 네트워크의 다른 PC에서 접속 가능).
- 포트 변경:  
  `YOLO_SERVER_PORT=5002 ./venv/bin/python app.py`  
  또는 `config/server_config.yaml` 에서 `port` 수정.

### 2.3 동작 확인

- 브라우저: `http://localhost:5001/` 또는 `http://<서버IP>:5001/`
- 터미널: `curl http://localhost:5001/health`  
  → `{"status":"ok","model":"loaded"}` 이 나오면 정상.

## 3. 제공 기능(엔드포인트) 요약

| 용도 | 메서드 | 경로 | 설명 |
|------|--------|------|------|
| API 정보 | GET | `/` | 서비스 설명·엔드포인트 목록 |
| 상태 확인 | GET | `/health` | 서버·모델 로드 여부 |
| 모델 확인 | GET | `/model_info` | 사용 중인 모델(best.pt) 경로·클래스명·로드 상태 |
| **이미지 분석** | GET | `/analyze/image` | 스냅샷 1장 분석 → 검출 결과 JSON |
| **영상 분석** | GET | `/analyze/video` | 영상 N프레임 분석 → 프레임별·전체 검출 JSON |
| 실시간 스트리밍(SSE) | GET | `/analyze/video/stream` | 프레임마다 검출 결과 스트리밍 |
| 영상 프리뷰 | GET | `/stream/preview` | 분석 결과가 그려진 영상 MJPEG 스트림 |
| 웹 뷰 | GET | `/view` | 브라우저에서 스트리밍·검출 상태 확인 |
| 모델 재로드 | POST | `/reload_model` | 설정 변경 후 모델만 다시 로드 |

**ROS2에서 자주 쓸 API**:  
- **한 장 분석**: `GET /analyze/image`  
- **여러 프레임 분석**: `GET /analyze/video` (선택: `?num_frames=5`)

## 4. 분석 결과 형식 (ROS2 연동 시 참고)

### 4.1 이미지 분석 `GET /analyze/image`

**성공 시 (200)**  
- `success`: true  
- `source`: `"snapshot"`  
- `image_size`: `{ "width": 640, "height": 480 }`  
- `detections`: 검출 배열  
  - `class_id`: 정수  
  - `class_name`: 문자열 (예: "m1", "m2", "m3")  
  - `confidence`: 0~1  
  - `bbox`: `[x1, y1, x2, y2]` 픽셀 좌표  
- `count`: 검출 개수  

**실패 시**  
- 503: JetBot 연결 실패 (`source_fetch_failed`)  
- 500: 추론 오류 (`inference_failed`)  
- body에 `success: false`, `error`, `message` 포함  

### 4.2 영상 분석 `GET /analyze/video`

**성공 시 (200)**  
- `success`: true  
- `source`: `"video_feed"`  
- `num_frames`: 분석한 프레임 수  
- `frames`: 프레임별 배열 (각 항목에 `frame_index`, `image_size`, `detections`, `count`)  
- `detections`: 모든 프레임 검출을 합친 배열 (형식은 위와 동일)  
- `total_detections`: 전체 검출 개수

## 5. 설정 파일

| 파일 | 위치 | 용도 |
|------|------|------|
| 서버 포트/호스트 | `config/server_config.yaml` | `port`(기본 5001), `host` |
| YOLO 모델·클래스 | `config/yolo_config.yaml` | `model_path`(예: best.pt), `class_names`, `conf_threshold` 등 |
| JetBot 주소 | `config/jetbot_config.yaml` | `base_url`(예: http://192.168.1.6:5000), 프레임 수·타임아웃 등 |

- **모델 교체**: `config/yolo_config.yaml` 에서 `model_path`, `class_names` 만 수정한 뒤, 서버 재시작 또는 `POST /reload_model` 호출.  
- **JetBot IP 변경**: `config/jetbot_config.yaml` 의 `base_url` 수정 후 서버 재시작.

## 6. 문제 해결

| 현상 | 확인·조치 |
|------|------------|
| 서버 접속 안 됨 | 방화벽에서 5001 포트 허용, `config/server_config.yaml` 의 `host`가 `0.0.0.0` 인지 확인 |
| 503 source_fetch_failed | JetBot(192.168.1.6:5000) 접속 가능 여부, `config/jetbot_config.yaml` 의 `base_url` 확인 |
| 검출이 안 됨 | `GET /model_info` 로 `model_path`, `model_path_exists`, `load_status` 확인. 필요 시 `conf_threshold` 낮춤(예: 0.15) |
| 포트 충돌 | `config/server_config.yaml` 의 `port` 변경 또는 `YOLO_SERVER_PORT` 환경변수 사용 |
