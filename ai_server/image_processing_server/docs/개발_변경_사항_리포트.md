# image_processing_server 개발 변경 사항 리포트

작성일: 2025-02-23  
대상: `ai_server/image_processing_server` (YOLO 영상/이미지 분석 Flask API)

---

## 1. 변경 요약

**요구사항**: `/view` 화면에 감지된 모델에 대한 **confidence(신뢰도)** 표시

**반영 내용**:
- 스트리밍 프리뷰와 연동한 최신 검출 결과 저장
- `GET /stream/latest` API 추가 (검출 목록·confidence JSON)
- `/view` HTML에 "감지된 모델 (confidence)" 섹션 및 0.5초 폴링 스크립트 추가
- 브라우저 캐시 억제로 항상 최신 HTML 로드되도록 처리

---

## 2. 변경 상세

### 2.1 모듈 전역 변수

| 항목 | 내용 |
|------|------|
| `_latest_detections` | 스트리밍 프리뷰(`_generate_preview_mjpeg`)에서 매 프레임 갱신되는 최신 검출 리스트. 각 요소: `class_id`, `class_name`, `confidence`, `bbox` |

### 2.2 스트리밍 생성기 수정

- **함수**: `_generate_preview_mjpeg()`
- **변경**: `global _latest_detections` 선언 후, 매 프레임 분석 결과를 `_latest_detections`에 할당 (성공 시 `detections`, 예외 시 `[]`)

### 2.3 API 추가

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/stream/latest` | 최신 검출 결과 스냅샷 반환. 응답: `{ "detections": [ { "class_name", "confidence", "bbox", "class_id" }, ... ], "count": N }` |

- `/stream/latest`는 `list(_latest_detections)`로 스냅샷을 만들어 반환 (스트림 스레드와의 경쟁 완화)

### 2.4 `/view` 페이지 변경

- **이전**: 스트리밍 이미지 + 메타 링크만 있는 단순 HTML
- **이후**:
  - **감지된 모델 (confidence)** 섹션 추가
    - `confidence-section`, `confidence-count`, `confidence-list` (id/class)
    - 검출 수 문구: "검출 수: N (0.5초마다 갱신)"
    - 리스트: 클래스명 + confidence(예: 95.3% 또는 —)
  - **스크립트**: 0.5초마다 `/stream/latest` fetch → 응답 JSON으로 목록 갱신, 오류 시 메시지 표시
  - **캐시 억제**: `<meta http-equiv="Cache-Control" content="no-cache, no-store, must-revalidate">`, 응답 헤더 `Cache-Control`, `Pragma: no-expires`
  - **경로**: `window.location.pathname` 기준으로 서브패스 대응 (예: `/yolo/view` → `/yolo/stream/latest`)
  - **안전 처리**: `class_name` HTML 이스케이프, `confidence` null/비숫자 시 "—" 표시

### 2.5 index 엔드포인트

- `endpoints`에 `stream_latest`, `view` 설명 갱신: "GET /stream/latest (최신 검출 목록·confidence, JSON)", "GET /view (스트리밍 + 검출 상태 + confidence 표시)"

## 4. 확인 방법

1. 서버 실행 후 브라우저에서 `GET /view` 접속
2. 스트리밍이 시작되면 "감지된 모델 (confidence)" 아래에 검출 클래스명과 confidence(%) 목록 표시
3. `GET /stream/latest` 직접 호출 시 JSON으로 `detections`, `count` 확인
