이후 2장(사전 준비)·7장(빌드 및 실행)·8장(토픽 사용)만 참고해도 됩니다.

## 1. 연동 개요

- **ROS2 노드**가 **YOLO 분석 서버**(Flask API)를 **HTTP GET**으로 호출합니다.
- 서버는 JetBot 카메라에서 이미지/영상을 가져와 YOLO로 분석한 뒤 **JSON**으로 결과를 돌려줍니다.
- ROS2에서는 이 JSON을 받아 **토픽**으로 발행하거나, 로직에서 바로 사용할 수 있습니다.

```
[JetBot 카메라 192.168.1.6:5000] → [AI 분석 서버 192.168.0.27:5001] ← HTTP GET ← [ROS2 노드] → /yolo/detections (토픽)
```

다음이 준비되어 있어야 합니다.

**서버 IP**: AI 분석 서버는 **192.168.0.27:5001** 입니다. 샘플 노드의 `SERVER_BASE_URL` 또는 launch 인자에 `http://192.168.0.27:5001` 로 설정하면 됩니다.

## 4. 샘플 노드 코드 (복사해서 사용)

아래 코드를 **그대로** 사용하면, 주기적으로 서버에 **이미지 분석** 요청을 보내고, 결과를 **JSON 문자열**로 토픽에 발행합니다.

### 4.1 파일 위치

- **경로**: `~/ros2_ws/src/yolo_analysis_client/yolo_analysis_client/yolo_client_node.py`  
- **주의**: `yolo_analysis_client` 폴더가 두 번 나옵니다 (패키지 이름/모듈 이름).

폴더가 없다면 만듭니다.

```bash
mkdir -p ~/ros2_ws/src/yolo_analysis_client/yolo_analysis_client
```

### 4.2 전체 코드 (yolo_client_node.py)

**파일 생성**:  
`~/ros2_ws/src/yolo_analysis_client/yolo_analysis_client/yolo_client_node.py`

```python
#!/usr/bin/env python3
"""
YOLO 분석 서버를 호출하고 결과를 ROS2 토픽으로 발행하는 노드.
- 서버 주소와 호출 주기만 수정하면 바로 사용 가능합니다.
"""

import json
import rclpy
from rclpy.node import Node
from std_msgs.msg import String


# ========== 여기만 수정하세요 ==========
# YOLO 분석 서버 주소 (AI 분석 Flask 서버 IP와 포트)
SERVER_BASE_URL = "http://192.168.0.27:5001"
# 이미지 분석 요청 주기 (초). 1.0 이면 1초마다 한 번 요청
ANALYSIS_INTERVAL_SEC = 1.0
# 사용할 API: "image" = 스냅샷 1장 분석, "video" = 영상 여러 프레임 분석
API_MODE = "image"  # "image" 또는 "video"
# ======================================


class YoloClientNode(Node):
    def __init__(self):
        super().__init__("yolo_client_node")
        self.declare_parameter("server_url", SERVER_BASE_URL)
        self.declare_parameter("interval_sec", ANALYSIS_INTERVAL_SEC)
        self.declare_parameter("api_mode", API_MODE)

        self.server_url = self.get_parameter("server_url").value.rstrip("/")
        self.interval_sec = self.get_parameter("interval_sec").value
        self.api_mode = self.get_parameter("api_mode").value

        # 분석 결과를 JSON 문자열로 발행하는 토픽
        self.pub_detections = self.create_publisher(String, "yolo/detections", 10)
        # 주기적으로 서버 호출
        self.timer = self.create_timer(self.interval_sec, self.timer_callback)
        self.get_logger().info(
            f"YOLO client started: {self.server_url}, mode={self.api_mode}, interval={self.interval_sec}s"
        )

    def timer_callback(self):
        import requests
        url = f"{self.server_url}/analyze/image" if self.api_mode == "image" else f"{self.server_url}/analyze/video"
        try:
            resp = requests.get(url, timeout=15)
            resp.raise_for_status()
            data = resp.json()
        except requests.exceptions.RequestException as e:
            self.get_logger().warn(f"Server request failed: {e}")
            return
        except json.JSONDecodeError as e:
            self.get_logger().warn(f"Invalid JSON: {e}")
            return

        if not data.get("success", False):
            self.get_logger().warn(f"Server error: {data.get('error', '')} - {data.get('message', '')}")
            return

        # 전체 응답을 JSON 문자열로 발행 (다른 노드에서 파싱해 사용)
        msg = String()
        msg.data = json.dumps(data)
        self.pub_detections.publish(msg)

        count = data.get("count", 0) if self.api_mode == "image" else data.get("total_detections", 0)
        self.get_logger().info(f"Published detections: count={count}")


def main(args=None):
    rclpy.init(args=args)
    node = YoloClientNode()
    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()


if __name__ == "__main__":
    main()
```

- **서버 주소**: 코드 상단 `SERVER_BASE_URL` 또는 launch/파라미터에서 `server_url` 로 변경 가능.  
- **주기**: `ANALYSIS_INTERVAL_SEC` 또는 파라미터 `interval_sec`.  
- **API 모드**: `API_MODE = "image"` → 스냅샷 1장 분석, `"video"` → 영상 여러 프레임 분석.

### 5.1 entry_points 추가

`setup.py` 안의 `entry_points` 블록이 아래와 비슷하도록 합니다 (이미 있으면 `console_scripts` 안에만 항목 추가).

```python
entry_points={
    'console_scripts': [
        'yolo_client_node = yolo_analysis_client.yolo_client_node:main',
    ],
},
```

즉, `yolo_client_node` 실행 시 `yolo_analysis_client.yolo_client_node:main` 이 실행되도록 합니다.

### 5.2 setup.py 전체 예시 (참고)

```python
from setuptools import setup

package_name = 'yolo_analysis_client'

setup(
    name=package_name,
    version='0.1.0',
    packages=[package_name],
    data_files=[
        ('share/ament_index/resource_index/packages', ['resource/' + package_name]),
        ('share/' + package_name, ['package.xml']),
        ('share/' + package_name + '/launch', ['launch/yolo_client.launch.py']),
    ],
    install_requires=['setuptools'],

    maintainer_email='your_email@example.com',
```

### 6.2 Launch 파일 (선택)

파라미터로 서버 주소·주기를 바꾸고 싶다면 launch 파일을 만듭니다.

**경로**: `~/ros2_ws/src/yolo_analysis_client/launch/yolo_client.launch.py`

```python
from launch import LaunchDescription
from launch_ros.actions import Node
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration


def generate_launch_description():
    return LaunchDescription([
        DeclareLaunchArgument("server_url", default_value="http://192.168.0.27:5001"),
        DeclareLaunchArgument("interval_sec", default_value="1.0"),
        DeclareLaunchArgument("api_mode", default_value="image"),
        Node(
            package="yolo_analysis_client",
            executable="yolo_client_node",
            name="yolo_client_node",
            parameters=[{
                "server_url": LaunchConfiguration("server_url"),
                "interval_sec": LaunchConfiguration("interval_sec"),
                "api_mode": LaunchConfiguration("api_mode"),
            }],
        ),
    ])
```

실행 예 (launch 사용 시):

```bash
cd ~/ros2_ws
colcon build --packages-select yolo_analysis_client
source install/setup.bash
ros2 launch yolo_analysis_client yolo_client.launch.py server_url:=http://192.168.0.27:5001
```

## 8. 분석 결과 토픽 사용하기

### 8.1 토픽 확인

다른 터미널에서:

```bash
source ~/ros2_ws/install/setup.bash
ros2 topic list
# 예: /yolo/detections
ros2 topic echo /yolo/detections
```

- `echo` 하면 서버에서 받은 **전체 JSON**이 그대로 출력됩니다.

### 8.2 JSON 형식 (이미지 분석 시)

이미지 분석(`/analyze/image`) 응답 예시는 다음과 같습니다.

```json
{
  "success": true,
  "source": "snapshot",
  "image_size": { "width": 640, "height": 480 },
  "detections": [
    {
      "class_id": 0,
      "class_name": "m1",
      "confidence": 0.92,
      "bbox": [100, 150, 300, 400]
    }
  ],
  "count": 1
}
```

- `detections`: 검출 목록.  
- 각 검출: `class_name`(예: m1, m2, m3), `confidence`, `bbox`(픽셀 [x1,y1,x2,y2]).

### 8.3 다른 노드에서 결과 파싱하는 예 (Python)

다른 ROS2 노드에서 `/yolo/detections` 를 구독해 사용하는 예시입니다.

```python
import json
from rclpy.node import Node
from std_msgs.msg import String


class MySubscriberNode(Node):
    def __init__(self):
        super().__init__("my_subscriber_node")
        self.sub = self.create_subscription(
            String,
            "yolo/detections",
            self.detection_callback,
            10,
        )

    def detection_callback(self, msg):
        data = json.loads(msg.data)
        if not data.get("success"):
            return
        detections = data.get("detections", [])
        for d in detections:
            class_name = d["class_name"]
            confidence = d["confidence"]
            bbox = d["bbox"]  # [x1, y1, x2, y2]
            self.get_logger().info(
                f"Detected: {class_name} conf={confidence:.2f} bbox={bbox}"
            )
        if not detections:
            self.get_logger().info("No detection")
```

- `data` 가 이미지 분석이면 위와 같이 `detections` 를 사용.  
- 영상 분석(`/analyze/video`)이면 `data["frames"]` 또는 `data["detections"]`, `data["total_detections"]` 를 사용하면 됩니다.

## 9. 영상 분석 API 사용 (video 모드)

여러 프레임을 한 번에 분석하려면 노드에서 `api_mode` 를 `"video"` 로 두거나, 직접 다음 URL을 호출하면 됩니다.

- URL: `GET http://<서버IP>:5001/analyze/video`
- 선택: `?num_frames=5` (분석할 프레임 수)

응답에는 `frames`(프레임별 결과)와 `detections`(전체 검출 목록), `total_detections` 가 포함됩니다.  
노드 코드에서는 이미 `API_MODE = "video"` 일 때 `url = .../analyze/video` 를 쓰고, `total_detections` 를 로그에 출력하도록 되어 있습니다.

## 10. 문제 해결

| 현상 | 확인할 것 |
|------|------------|
| `Server request failed` | 서버가 떠 있는지, `server_url` IP·포트가 맞는지 확인. 같은 PC면 `http://127.0.0.1:5001` |
| `Published detections: count=0` | 서버는 정상이나 검출 없음. 카메라 화면·조명·모델(best.pt) 확인 (서버 매뉴얼 참고) |
| `ModuleNotFoundError: requests` | `pip3 install requests` 또는 package.xml에 `python3-requests` 추가 후 재빌드 |
| 노드가 안 보임 | `source install/setup.bash` 한 뒤 `ros2 run yolo_analysis_client yolo_client_node` 다시 실행 |
