## 4. app/gui

### 4.1 요구사항 대응
- **ModuleNotFoundError: No module named 'yaml'**  
  - **조치**: `app/gui/requirements.txt`에 `PyYAML>=6.0` 추가. 사용자 venv에서 `pip install -r requirements.txt` 실행으로 해결.
- **qt.qpa.xcb: could not connect to display**  
  - **조치**: 환경 대응 안내. 로컬이면 `export DISPLAY=:0`, Wayland면 `QT_QPA_PLATFORM=wayland`, SSH/헤드리스면 `xvfb-run` 또는 GUI를 디스플레이 있는 PC에서 실행하도록 안내.
