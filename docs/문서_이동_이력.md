# 문서 이동·재배치 이력

작성일: 2025-02-23  
대상: 프로젝트 루트 `docs/` 및 개발 영역별 `docs/` 정리

---

## 1. 개요

- **목적**: 각 개발 카테고리에 맞게 문서를 해당 영역의 `docs/` 폴더에서 관리하도록 재배치.
- **원칙**: 프로젝트 전체 공통 문서는 루트 `docs/` 유지, 영역 전용 문서는 해당 영역 `docs/`로 이동.
- **fms 관련**: fms 디렉터리 관련 작업은 수행하지 않음 (skip_mode_guide.md 등은 루트 `docs/`에 유지).

## 3. 루트 docs에 유지한 문서

- `README.md` — 문서 인덱스·개요 (개발 영역별 문서 위치 섹션 추가)
- `요구사항_진행_현황_리포트.md` — 프로젝트 전체 요구사항 진행 현황
- `external_interfaces.md` — FMS·외부 팀 인터페이스 명세 (전체 공통)
- `skip_mode_guide.md` — Skip mode 테스트 가이드 (루트 유지, fms 작업 미수행)
- `INTEGRATION_QUICKSTART.md` — 통합 퀵스타트 (전체 공통)
- `docs/scripts/` — `verify_backend_db.py`, `check_pinky_robot_store_db.py` (Backend DB 검증용, 루트 docs 하위 유지)

## 4. 정리 후 삭제한 원본(중복 제거)

- `docs/backend_db_호환성_점검_계획.md` — `app/backend/docs/`로 이동 후 루트 복사본 삭제
- `docs/OBSTACLE_AVOIDANCE_SETUP.md` — `mobile_robot/docs/`로 이동 후 루트 복사본 삭제

## 5. 참고

- Backend DB 검증 스크립트는 계속 **프로젝트 루트 `docs/scripts/`** 에서 관리 (경로: `docs/scripts/verify_backend_db.py`, `docs/scripts/check_pinky_robot_store_db.py`).
- 개발한 소스·설정 파일은 변경하지 않았으며, **문서만 이동·수정**함.
